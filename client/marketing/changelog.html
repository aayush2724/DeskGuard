Changelog

What's new

Product updates, big and small, taken from the project's release history.

October 2026

Production readiness

  • Honest marketing copy, privacy policy, and terms that describe what the app actually does
  • Working contact form, custom 404 page, page-specific metadata, sitemap and robots.txt
  • Accessibility pass: keyboard-navigable desk map and modals, labelled forms, visible focus, better colour contrast
  • Self-hosted fonts and scripts (no third-party requests), smaller bundle, security headers
  • API now rejects impossible desk transitions (for example checking in to an occupied desk)
June 2026

Production deployment

  • Website and app deployed on Vercel with the API on Render
  • Librarian endpoints protected by an access key; "Print QRs" button added to the dashboard
  • Script to initialise a remote database and seed the demo floor
June 2026

Security hardening

  • Rate limiting, input validation, and security headers on the API
  • Access-key authentication for staff actions
June 2026

Visual refresh

  • Plum and gold theme across the website and app
  • Bookshelf features section and consolidated navigation
  • Scanner fixes and a new librarian dashboard layout
June 2026

Initial release

  • Live isometric desk map with real-time updates over server-sent events
  • QR check-in, Away hold, and Still here? confirmation flow
  • Background sweep that flags abandoned desks
  • Librarian dashboard with desk registry, reset actions, and activity log
